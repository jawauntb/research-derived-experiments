# The dial's optimal rate falls; its cells need not nest

All 52 partitions of a registered five-point world: rates
(5, 3, 2, 2, 1) fall along the budget, the D = 0 optimum is the level
partition, all-optimizer nesting fails with an explicit witness, and
a chosen chain still nests — nesting is a selection fact. Settles
review item 2 on the intention essay. Companion instrument:
`experiments/dial_nestedness/`. Not Paper G.
