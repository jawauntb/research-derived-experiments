## Severe experiment

Package: `experiments/delete_repair_swap/`.
World: the same 16-point cube.
Over toy: `first_bit`. Typed screens `q_stab0` / `q_id`. Crossed
screen `q_perm`.
Under toy: `bag`. Typed screen `q_perm`. Crossed screen `q_id`.

Honesty: the representability bits are Paper A's. The new object is
the pairing plus the kill rule. A pass is the expected result if A
was transported correctly *and* the pairing discriminates. That is
weaker than a new census. It is still the test A said it owed.

Fatal instrument gates (all passed; a taxonomy kill would still
pass these):

| Gate | Fact |
|---|---|
| `SWAP_ENUMERATION` | 16 worlds |
| `SWAP_TYPED_OVER_REPRESENTABLE` | `q_stab0` and `q_id` represent `first_bit` |
| `SWAP_TYPED_UNDER_REPRESENTABLE` | `q_perm` represents `bag` |
| `SWAP_BOTH_CELLS_RECORDED` | both toys present |
| `SWAP_RANKING_RECORDED` | `taxonomy_holds` |
| `SWAP_CLAIM_BOUNDARY` | E/F, DR/DCR, Lorentz identification withheld |

Observed:

| Toy | Typed | Crossed |
|---|---|---|
| `first_bit` | `q_stab0` representable, 8 fibres | `q_perm` **not** representable, 5 fibres |
| `bag` | `q_perm` representable, 5 fibres | `q_id` representable, 16 fibres |

Typed wins. Crossed over-repair fails. Under-quotient is strictly
cheaper. `q_perm` is not safe for both. `q_id` is safe for both but
not fibre-minimal for `bag`. Verdict: `taxonomy_holds`.

Kill was: crossed over-repair represents `first_bit`, or the
under-quotient is not cheaper, or one screen is minimal-safe for
both. None of those happened.
