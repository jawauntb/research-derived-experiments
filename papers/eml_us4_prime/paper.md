## Current frame

After the monomial toy, the tempting transfer is: EML access is a
*spectrum of shells*, so extra inhabitants at larger size move discovery
probability the way Sq extra shells moved `P(x^{16})`. Shortest depth

The protected assumption is that the toy's extra-shell geometry is the

On this truncated language, Gibbs access is **min-shell multiplicity**,
not extra shells and not shortest depth. The identically-zero function


## Claim boundary

**Supported.** On this truncated language, Gibbs mass is not a function
of shortest depth. The zero function has two exact size-3 formulas.
Size-class order is preserved (0 inversions). Extra-shell factor
`< 1.05`.

**Withheld.** Master-formula gradient recovery. The Sq extra-shell
mechanism as the EML access law. Function identity from the grid
except the zero identity. Any claim that Gibbs base 4 is canonical.

**What would change the conclusion.** A `k=3` finite class with all
fibers singleton; a later bound where extra shells move mass by a
factor `≥ 1.25` without a multiplicity split; a gradient-recovery
ranking that tracks min-size and not `Φ`.
