# Completeness is not discovery

You can write down every answer and still not know how to reach the ones that matter.

That claim is not a mood. It is the conclusion of a finite argument. The premises are toys a person can hold — four bits, a sort, a count — and a short list of lemmas, each of which had a kill test. Most of those tests are now theorems. A few measurements we refused to promote. At the end there is a QED, of a kind: not "therefore the universe," but "therefore this, and not the other thing, on the harness we actually ran."

A reader who has followed a philosophical argument before — premises, objections, what would count as a refutation — has enough. The mathematics is here. You are not asked to learn a course to watch the argument close.

---

## What the words mean

Sixteen worlds. Each world is four bits, on or off. A *task* is a question about a world: what is the first bit, how many bits are on, do the first two agree. A *screen* is a way of throwing information away before you answer. Sort the four bits. Keep only the first. Keep everything. Keep nothing that matters.

After a screen, some worlds look the same. Those are a *fiber* — the bucket of worlds the screen cannot tell apart. The task is *representable* from the screen when every fiber is unanimous: worlds that look the same still get the same answer. If a fiber splits, you deleted something the question still uses.

The coarsest representable screen — the one that throws away as much as possible and still determines the answer — is an old object. Statisticians call it a sufficient statistic (Halmos and Savage, 1949). In this program it is Theorem 4. We did not invent it. We used it.

*Gold*, below, is the repair a disclosed menu of screens actually warrants: restore a lost distinction, quotient a leftover privilege, transport across charts, or stay. It is not a vibe. It is computed from representability on that menu.

## Lemma 1. Existence is not access

Odrzywołek (2026) showed that one binary operator, `eml(x, y) = exp(x) − ln(y)`, plus the constant `1`, writes every scientific-calculator button. Completeness there means: for each output, some input tree exists. The fiber is inhabited.

Inhabited is not found. Found is not worth finding. "Write all," "reach all," and "care which matter" are three jobs. A tradition that treats the first as the second will keep announcing discovery when it has only announced a grammar. We keep them split. Concern — which answers matter — was never this program.

What would kill the split: a demonstration that inhabitation already is search, on the same objects. We do not have one.

## Lemma 2. Over-invariance is a real cell

Ask for the first bit. First sort the four bits. Sorting forgets position. The first bit is a position. Fibers now mix yes and no. The task is not representable. The repair is to put the distinction back — a finer screen, or the identity.

This is the content-only attention failure in miniature (Vaswani et al., 2017, as a warning, not as a theorem about transformers). You quotiented away order the task still uses. "More symmetry" is the wrong name for that.

Lean: the n=4 matrix, `dta_n4_representable_iff`. On this harness, representable if and only if the screen's symmetries sit inside the task's. Sort is not inside "first bit." Verified.

## Lemma 3. Under-invariance is a different cell

Ask how many bits are on. The identity screen still works. It is wasteful. Sixteen buckets where five would do — zero through four ones. Sorting now represents, and is cheaper. The leftover coordinate is privilege, not a no-go. The repair is to throw it away.

What would collapse Lemma 2 into Lemma 3: the same repair fixing both toys. That is the next lemma's kill test.

---

## Lemma 4. Opposite repairs are not interchangeable

This is the one-arrow objection, taken seriously. EML and the relativity slogan both look like a deletion. Maybe there is one motion, and the two cells are costumes.

Paper B crosses the repairs. On the first-bit toy, the typed restore works (`keep bit 0, sort the rest`; also the identity). The crossed repair — sort everything, the under-invariance move — fails. On the count toy, the typed quotient works and is cheaper (5 fibers versus 16). The identity still represents; it is just the expensive stay.

Typed wins. Crossed over-repair fails. One ladder is dead on this harness.

Lean: `swap_typed_wins`. Verified.

## Lemma 5. Adding the labels is not the general connection

A third cell is comparison across charts. On ordinary additive cycles, Kirchhoff still holds: the result of the path is the sum of the edge labels. The control is honest.

On a tiny affine group — pairs `(a, b)` with `(a,b) ∘ (c,d) = (ac, ad + b)` modulo 3 — there exist 4-cycles whose path-ordered result is not that sum. Additive cycles still match. Affine ones escape. Composition does not even commute.

Steelman: maybe this is Lorentz, or a spacetime theorem, or the same object as a Lamport clock. It is not. We did not recover Einstein 1905 or Lorentz 1904. We recovered a finite witness that "just add the `b`s" is not the general transport.

Lean: `affine_escapes_kirchhoff`. Verified. No axioms.

## Lemma 6. A shared cartoon is not a shared theorem

Take two events that do not order each other. Philosophers of time and computer scientists both know this picture: the causal diamond, happens-before (Lamport, 1978), the interval of special relativity. The hope — and it is a real hope — is that they are the same theorem in different clothes.

Embed the diamond on a 4×4 grid. There are 196 exact diamonds. The two events stay concurrent in every embedding. The interval `s²` takes four values: −1 (128 times), −3 (32), −4 (32), −8 (4). Concurrency is constant. The number you would like to call distance is not. Happens-before is not `ds²`. There is no functor here.

Lean: `poset_not_determine_interval`. Verified. No axioms.

What would reopen the identification: a forgetful map, stated, that sends the Lorentz theorem to the Lamport theorem and the diamond to both, and survives this fibre. We do not have one.

## Lemma 7. A cheap signature is not a function, and not an agent

The objection from the other side: you do not need the menu. Five numbers should be enough — does the screen mix the answer, how many buckets, how many worlds, is there unused symmetry, did the path labels fail to add. A one-shot rule. An agent could carry it.

Built on the toys it was written for: 4/4. Held out: 6/7.

The miss is whether the first two bits agree, seen through the identity. There is unused symmetry — later bits can move and the answer stays. The rule says quotient. No cheaper screen on the registered menu still determines the answer. Unused symmetry is not leftover privilege.

Then the same five numbers, on four different questions, split the right action. Three want quotient. One wants stay. A "function" that sends one input to two outputs is not a function.

Lean: `surgery_miss_pair_eq`; `kappa_cheap_not_function`. Both verified.

What would save the cheap rule: a larger held-out menu, still not trying repairs, with no collision. Fitting a sixth number to erase the miss is not that test. We did not do it.

## Lemma 8. The map that works is the old theorem plus an order

We wrote the function before looking at the miss, not after.

Look at the disclosed menu. If the path labels fail to add, transport. Otherwise take the coarsest menu screen that still determines the answer — fewest buckets, then the name — and restore, quotient, or stay against the screen you have. This is Theorem 4, evaluated on a finite menu, plus a total order we named in advance.

It hits 11/11. First-bit goes to "keep bit 0, sort the rest." Last-bit goes to the symmetric choice. Count goes to sort. The miss stays on the identity and does nothing.

Uniqueness fails. Count is representable from all five menu screens. The order picks one. Relabel bit 0 with bit 3 and the first-bit story becomes the last-bit story. Names are not essence. Two different "delete the absolute" schedules still disagree on a two-point example; that theorem was already on the books and we reused it.

Lean: `kappa_screen_hits_suite`; `bag_not_unique`; `kappa_relabel_natural`; `repair_paths_disagree` (prior, cited). All verified. The screen lemma was first proved with a native shortcut; that is not an audit. Kernel `decide` plus SafeVerify is. A green compile is not.

What would kill "a function exists": a registered case the menu map misses. It did not miss. What would make it a *new* calculus: a map that never looks at the menu and still hits. That is Lemma 7, and it died.

## Lemma 9. Access is process-relative — and we did not theorem-ize the ratios

Under a sampler that weights fibers by mass, discovery probability is not shortest depth. On one small pair the sampler feels a gap (about 2 to 1). A search that can see the tree barely feels it (8/8 versus 6/8). A search that cannot see the tree ties, 7 versus 7. A frozen-leaf rewrite feels extras 43 versus 28, which is not the 2.016.

One search law is false as a law. Those counts stay Python. They are measurements. Promoting them to Lean would be a different paper, and a dishonest one if we treated 43/28 as the same object as the sampler's ratio.

## What this is not

A better language model. A new master object above the sufficient screen. A unique repair schedule. Continuum Lorentz. Valence, agency, consciousness. A nomination of Einstein's deletion from the 1905 text. `Complex.log 0`. Someone else's 2026 writeup, laundered into a theorem.

If the frame is right, a better model would reuse a subroutine instead of reprinting it — name `sq(y) = y·y` and the formula for `x` to the `2^n` drops from `2^{n+1}−1` multiplies to `n+1`, while the circuit stays the same size — would not delete working distinctions, would not keep a fake privileged coordinate, and would not install one search law. Completeness is cheap once the substrate exists. Access is the bottleneck. Concern is later. None of that shipped here.

---

## QED

Assume a finite menu of screens and a finite family of tasks on sixteen worlds. Then:

1. Representability is fiber-unanimity, and on this harness it is exactly "the screen's symmetries sit inside the task's."
2. Restore and quotient are opposite repairs. Crossing them fails.
3. Path-ordered affine holonomy is not integer Kirchhoff.
4. A shared diamond poset does not determine an interval.
5. No cheap five-field signature is a function to the right repair, and the one we tried misses a held-out case for a reason that is not leftover privilege.
6. The map that looks at the menu, takes the coarsest representing screen, and names a tie-break, hits every registered case. It is the 1949 sufficient screen plus an order. It is not a new primitive.

Therefore the upgrade dies, and the dynamics remain. Completeness is not discovery. Delete–repair is typed motion on a frontier we already had. The repair function is the menu you were willing to try.

That is as much QED as a finite harness will bear. A later fact that cannot be written as a movement of a screen — or a cheap map that never looks at the menu and still hits a larger held-out family — would reopen it. We do not have either. We are not owed either.
