## 1. Current frame

Odrzywołek showed that one binary operator

```
eml(x, y) = exp(x) − ln(y)
```

with constant `1` inhabits the scientific-calculator class
(arXiv:2603.21852). The constant grammar is
`S → 1 | eml(S,S)`. The variable grammar is
`S → 1 | x | eml(S,S)`.

Completeness there is fiber inhabitation: `q⁻¹(z) ≠ ∅`. Every
calculator button is some tree. That is not discovery.

Structural Intelligence (SIC) already has the objects you need
once inhabitation is granted:

- a master fibration `(q, K)`
- a common-sufficient screen (Theorem 4 / Halmos–Savage)
- an abstraction frontier that is an antichain (AF-1 / AF-2)
- a catalog of lifts (RR-1 / RR-2), which is existence, not a
  map from failure to lift
- a cocycle test for gluing charts (TA-1)

The protected assumption, after the first EML toys and the
relativity slogan, was that one more arrow — “delete the
absolute, repair the relations” — would supersede that stack
and also explain attention, Lamport clocks, and Lorentz
geometry.

It does not. The arrow is real as *dynamics*. It is not a
second master object.

## 2. How this relates to better language models

It does not relate by putting `eml` in a transformer.

If the frame is right, a better model does four concrete
things. None of them were shipped here.

1. **Search at sharing / DAG level, not formula unrolling.**
   Adjoin a definable `sq(y) = y·y` to `{x, ×}`. The shortest
   *formula* for `x^(2^n)` drops from `2^(n+1)−1` to `n+1`.
   Circuit size stays `Θ(n)`. An expander that reprints the
   same subroutine in every residual stream is paying the
   formula tax. Weight tying, named tools, and recurrent reuse
   are the compiler move. `eml` is not the architecture.

2. **Do not delete working distinctions.** Content-only
   attention is over-invariance. It quotients away order the
   task still uses. Restore the distinction. Do not call that
   “more symmetry.”

3. **Do not leave an unearned privileged coordinate.** A
   leftover absolute frame is under-invariance. The identity
   still represents; it is just more expensive. Quotient the
   privilege or add transport. Do not call that “more
   features.”

4. **Do not install one search law.** Under a Gibbs prior,
   discovery probability is fiber mass `P(z) = Φ_z / Z`, not
   shortest length. Gibbs sampling feels `Φ`. Known-tree
   gradient descent barely feels `Φ`. Unknown-tree gradient
   descent does not. Frozen-leaf rewrite feels `Φ` again.
   `Φ` is process-relative.

“Discover all” splits into three jobs this program refuses to
smash:

| Job | Object | Status |
|---|---|---|
| Write all | completeness / inhabitation | Odrzywołek; not ours |
| Reach all | access / process-relative mass | banked as a split |
| Care which matter | concern / valence | **not done** |

A better language model would *reach* the programs that
matter, without deleting the distinctions those programs use,
and without a fake privileged coordinate. Completeness is
cheap once the substrate exists. Access is the bottleneck.
Concern is a later paper and is not hidden inside
`e^x − ln y`.

**Not shipped:** a better LLM.

- Expressivity ≠ tree size ≠ circuit size ≠ access.
- Access is process-relative on the registered size-3 EML
  pair (Gibbs / known-tree GD / unknown-tree GD / frozen-leaf).

  menu, and it is SIC’s screen plus a total order.

**Not supported.**

- A new master object above SIC.
- A cheap signature that does not try the menu.
- A unique repair schedule.
- A functor Lorentz ≅ Lamport ≅ PE.
- Continuum Lorentz, CG-2, or real spacetime.
- Variable-`x` EML as a DP-able spectrum with a 1-D invariant.
- Neural bootstrap (Odrzywołek’s actual search).
- Text nomination of deletions.
- Valence, concern, agency, consciousness.
- Paper 0 / `Complex.log 0` as part of this path.
- OpenAI 2026 writeups as theorems.
- A better language model.

**What would change the conclusion.**

- A cheap signature with no collision on a larger held-out
  menu that still does not try repairs → reopen a non-SIC κ.
- A functor with a stated forgetful map for Lorentz / Lamport /
  PE → reopen Possibility 6.
- A delete–repair phenomenon outside `(q, K)` → Possibility 5
  dies, and we would have something new.
- A later harness where crossed B-repairs work → drop the
  dual-instance claim.
