# Obstruction-Aware Admission

The manuscript is [`paper.md`](paper.md). Its executable evidence is in
`experiments/obstruction_aware_admission/`.

Build the PDF with:

```bash
uv run --no-sync python scripts/build_obstruction_aware_admission_pdf.py
```

The builder writes:

- `papers/obstruction_aware_admission/paper.pdf`;
- `papers/pdf/obstruction_aware_admission.pdf`; and
- a dated copy in `/Users/jawaun/Metaphysics of Intelligence/` when that
  existing archive directory is available.

The paper claims exact finite control, not new optimal decision-tree
mathematics or natural-domain agent performance.
