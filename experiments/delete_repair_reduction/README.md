# delete_repair_reduction

Door 2 of the close-out (`papers/sic_dynamics/paper.md` §12): is there
a delete–repair fact that cannot be written as a movement of (q, K)?

Answer at this bound: yes, and it was already banked under another
name. The squaring-macro episode — delete `sq` from `{x, ×, sq}`,
obstruction is the formula tax, repair is re-adjoining — changes the
access table (min size for `x^4`: 7 vs 3; fibre mass at the bound:
5 vs 14) while every registered screen partition (`q_den`, `q_size`,
`q_depth`) on the shared tree universe is extensionally identical and
the round trip is the identity. One (q, K) input, two required access
outputs: min size is not a function of (q, K).

The fact lives on the generator set — the process coordinate. This
bounds Possibility 5's dynamics reading instead of killing it:
representability facts move (q, K); generator-episode access facts do
not. That border is where the close-out's "access is process-relative"
split already pointed.
