# Live OpenAI claim-boundary results — 2026-09-03

## Result

The final frozen 16-case, three-repetition K562 matrix passed **48/48** on the
reviewed natural-language boundary, which combines four controls:

1. a deterministic check that requires exactly one explicit directional
   predicate before any model call;
2. a positive whole-sentence grammar that admits only one complete active-voice
   K562 knockdown claim and refuses every prefix, suffix, extra clause, context,
   modifier, citation, or command before any model call;
3. deterministic binding that requires distinct parser gene symbols to occur
   exactly once in subject → knockdown → predicate → object order and refuses
   extra known HGNC symbols;
4. the pinned `claim_parser/k562_gene_effect@v2` prompt, which treats model
   output as an untrusted three-field interpretation; and
5. the deterministic evidence checker, which alone assigns the verdict,
   fault code, rule, and evidence id.

The earlier failures remain part of the result. The v1 baseline passed
9/36. The prompt-only v2 run passed 33/36 but failed all three repetitions of
the multiple-claim ambiguity case. An initial single-predicate boundary then
passed 36/36, but code review found that it did not independently bind the
parser's returned direction and gene symbols to the user's text. The reviewed
token-bound boundary closed those gaps and re-passed 36/36. A final self-audit
then caught that the two present gene tokens could still be swapped; the
role-bound boundary closed that path and again passed 36/36. A final independent
release review then found that negation, wrong context, and repeated entity
mentions could still change claim semantics. The scope-bound boundary closed
those paths and passed 42/42. Follow-up review showed that any finite context or
causality blacklist remained bypassable (for example HEK293 or “drives”). The
positive-grammar boundary replaced that blacklist, added two more attacks, and
passed 48/48 without changing the prompt, checker rules, evidence, or prior run
records.

This is a boundary-control result, not a new biological result. It supports a
narrow claim about this pinned OpenAI model and frozen K562 test matrix. It does
not establish the truth of the underlying Replogle 2022 edges, general
biological fact checking, cross-model robustness, cross-world robustness, or
clinical safety.

### Rejected and superseded stages

The v1 prompt is rejected for this use. In 18/36 repetitions it failed exact
interpretation, chiefly because it replaced literal gene symbols with varying,
incorrect HGNC CURIEs. That identity drift converted supported, reversed, and
missing-pair inputs into unrelated `INCONCLUSIVE` checks. It also failed the
expected-refusal gate on ambiguity and scope overclaims.

The prompt-only v2 configuration fixed the observed identity drift, scope
refusals, sign reversals, missing-pair behavior, and injection cases. It is
still rejected as a standalone boundary because all three LIVE-07 repetitions
silently selected the first claim from a two-claim sentence and returned
`ACCEPTED_CONDITIONALLY`.

The initial 36/36 result remains as a superseded engineering checkpoint. It
closed the observed two-predicate failure but did not prove that a parser could
not substitute a different direction or gene pair on a one-predicate input.
The token-bound review added direction and token checks but remained
superseded because it did not enforce subject/object roles. The role-bound
review added positional role binding but remained superseded because it did not
bind negation, context, perturbation type, or repeated mentions. The scope-bound
run closed those observed examples but remained superseded because its finite
blacklist could not cover unknown contexts or causal wording. The final positive
grammar run is the only passing boundary promoted into the public receipt.
None of these later results erase the v1 or prompt-only failure records.

## Discovery-regime audit

- **Action class:** search and verifier-boundary improvement inside the existing
  K562 claim schema; no discovery claim.
- **Accepted artifact:** the reviewed positive-grammar input/output
  contract, pinned v2 parser, and deterministic checker cleared the frozen
  48-repetition gate after two review rounds identified semantic substitutions
  and supplied four new attacks.
- **Rejected artifacts:** v1 at 9/36 and prompt-only v2 at 33/36.
- **Transported evidence:** existing K562 ledger records and deterministic rule
  cascade; this run did not add or independently validate biological evidence.
- **Residual risk:** paraphrases outside the deliberately narrow accepted
  grammar, other models/providers, and natural-language paths for non-K562
  evidence worlds remain untested by this matrix.
- **Next decisive test:** freeze a held-out paraphrase set and run it across at
  least one additional model/provider before claiming parser robustness; test
  each additional evidence world with its own scoped controls before claiming
  broader biological coverage.
